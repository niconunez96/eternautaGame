# Kenney visual sources

This directory contains the deliberately small source-art subset used by the playable slice.

- **Pack:** [Platformer Art: Pixel Redux](https://kenney.nl/assets/platformer-art-pixel-redux)
- **License:** [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)
- **Downloaded:** 2026-11-03
- **Upstream attribution:** Kenney Vleugels / [kenney.nl](https://kenney.nl/)

## Retained files

- `characters/spritesheet.png` — player, chalet props, exterior props, floor/roof decoration, snowfield, and terminal frame regions.
- `LICENSE.txt` — license text retained from the pack.

The official Kenney download endpoint returned HTTP 403/404 in this environment. The retained source files were fetched from an exact-content GitHub mirror at commit [`76052daa6de9770d4af28a7d550bd42fbf6344c3`](https://github.com/bitDecayGames/Jump/tree/76052daa6de9770d4af28a7d550bd42fbf6344c3/Kenney/assets/platformer-art-pixel-redux), whose included `license.txt` identifies the same Kenney Platformer Art Deluxe (Pixel Redux) CC0 source. The official pack URL above remains the canonical source.

Godot-generated import artifacts belong under ignored `.godot/`; only these curated source files are versioned.
